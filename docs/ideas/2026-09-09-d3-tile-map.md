## Maszyna stanów (przepływ prod — sterowany kafelkami)

```python
open_rewards()
loop (max 6 rund):
  tiles = read_tiles()   # {search, rte, cards, checkin, rendered}
  if all_terminal(tiles): break   # rendered-guard: blank render ≠ terminal
  if tiles.checkin: check_in()
  if tiles.cards:   misc_cards()  # quiz-karty wykrywane i przeklikane (_quiz_flow)
  if tiles.rte active: read_to_earn_flow(max_total = 30-done)
  if tiles.search active: required_searches(kap = 15-done)
  re-read daily_points; Δ=0 po rundzie (rnd>1) → konto saturated → break
```

Kolejność: check-in → pool cards (w tym quizy) → RTE → search. Po KAŻDYM etapie
odczyt daily_points; Δ=0 = kategoria martwa → nie wracamy. Puzzle i Daily set NIE
są etapami — puzzle to tracker 7-dniowy, Daily set śledzi pozostałe akcje.
